# Cellar — copy

**This page is nearly empty, and that is correct.** The server is headless — the MCP client is the UI (`README.md:39`), so user-visible strings are composed by whichever agent is connected, from the structured data a tool returns. The cellar feature owns no rendered text.

Only two categories of server-authored string exist, and neither belongs to this feature:

| Key | Source text | Placeholders | Where it appears |
| --- | --- | --- | --- |
| permission denial | `Permission denied: '<tool>' requires '<permission>'; your role is '<role>'.` | tool, permission, role | Any denied cellar call; owned by [[authorization-index]] (`README.md:139`) |
| tool descriptions | *(not specified)* | — | `tools/list`; these are the text a model reads to decide whether to call `cellar_add` — see [[mcp-protocol]] |

## Copy that asserts a rule

None from this feature. The one string the cellar produces indirectly — the permission denial — asserts a rule and **is** enforced: the message is generated by the same execution-layer check that rejects the call (`README.md:136`), so it cannot drift from the behaviour it describes.

The reverse risk is the one that matters here. Tool descriptions in `tools/list` are the only place the *semantics* of `drink_soon`, `ready_to_drink`, or the last-bottle rule could be stated to a model, and no text for them is specified. A description that says "drink_soon: window closing soon" without stating `N` would be copy asserting a rule the code has not defined — see [[cellar-states]].

## Not localized

Nothing is localized, and no localization system is specified. The permission-denial message is English, hard-coded, and structured for a machine reader rather than a human one — reasonable for this surface, but it means a non-English client surfaces an English string or paraphrases it.

The engine's `reasons` strings are the project's one substantial body of user-facing text (`README.md:263`–`270`) and carry the same constraint. They belong to [[recommendation-engine-index]]; one of them — *"Drink window closes in 5 months"* — is generated from cellar data.
